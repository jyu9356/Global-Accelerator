# Global-Accelerator

Enrolled in "Global Career Accelerator" as part of FSTDY 300, a course at the University of Washington during the summer quarter of the 2025-2026 academic year. The Global Career Accelerator program (https://globalcareeraccelerator.org/) is a course delivered via partnerships with over 100+ universities that aims to help students develop practical career skills and experience with leading companies.
